# Прогнозирование цитируемости научных статей на основе гетерогенных графов со временными весами
## Выполнил студент М8О-202СВ-25 Марченко Алексей Эдуардович

Научно-исследовательская работа, посвящённая разработке методики прогнозирования долгосрочной цитируемости научных публикаций с использованием гетерогенных графовых нейронных сетей и временных весов связей.

## О работе

Классические библиометрические индикаторы (импакт-фактор журнала, индекс Хирша) описывают уже состоявшееся влияние и не позволяют оценить перспективность новой публикации. В данной работе научный ландшафт представляется в виде гетерогенного графа, узлы которого — статьи, авторы, журналы и ключевые слова, а рёбра отражают типы взаимодействий между ними. Временные веса позволяют учитывать динамику накопления цитирований.

## Цель

Разработка воспроизводимой методики прогнозирования долгосрочной цитируемости научных публикаций на основе гетерогенных графовых структур с интеграцией динамических временных признаков.

## Задачи

1. Сформировать схему гетерогенного графового представления научных данных.
2. Собрать и предобработать массив библиометрических и семантических данных.
3. Разработать нейросетевую архитектуру для обучения на гетерогенном графе с временными весами.
4. Провести валидацию и сравнить модель с классическими методами ML и библиометрическими индикаторами.
5. Интерпретировать факторы прогнозной силы.

## Стек

Python, PyTorch Geometric, Hugging Face Transformers, scikit-learn, NetworkX, Pandas, NumPy, Semantic Scholar API / OpenAlex.
