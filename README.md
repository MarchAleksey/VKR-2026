# Прогнозирование цитируемости научных статей на основе гетерогенных графов со временными весами
## Выполнил студент М8О-202СВ-25 Марченко Алексей Эдуардович

Научно-исследовательская работа, посвящённая разработке воспроизводимой методики прогнозирования долгосрочной цитируемости научных публикаций с использованием гетерогенных графовых нейронных сетей и временных весов связей.

## О работе

Классические библиометрические индикаторы (импакт-фактор журнала, индекс Хирша) описывают уже состоявшееся влияние и не позволяют оценить перспективность новой публикации в момент её появления. Существующие модели прогнозирования цитируемости опираются на табличные признаки и рассматривают статью изолированно от её окружения в сети научного знания.

В данной работе научный ландшафт представляется в виде гетерогенного графа, узлы которого соответствуют статьям, авторам, журналам и ключевым словам, а рёбра отражают различные типы взаимодействий между ними. Введение временных весов позволяет учитывать динамику накопления цитирований и эволюцию тематических связей.

## Цель работы

Разработка воспроизводимой методики прогнозирования долгосрочной цитируемости научных публикаций на основе гетерогенных графовых структур с интеграцией динамических временных признаков, обеспечивающей устойчивое ранжирование новых статей по их будущему влиянию.

## Задачи

1. Выполнить аналитическую постановку задачи и сформировать схему гетерогенного графового представления научных данных.
2. Сформировать и предобработать интегрированный массив библиометрических и семантических данных.
3. Разработать и реализовать нейросетевую архитектуру для обучения на гетерогенном графе с временными весами.
4. Провести валидацию прогнозной модели и сравнить её с классическими методами машинного обучения и библиометрическими индикаторами.
5. Интерпретировать факторы прогнозной силы и сформировать рекомендации по практическому использованию.

## Методы

- Библиометрический анализ
- Теория графов
- Графовые нейронные сети (R-GCN, HGT)
- Трансформерные эмбеддинги научных текстов (SciBERT, SPECTER)
- Методы объяснимого ИИ (GNNExplainer, механизмы внимания)
